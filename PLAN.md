## Data Model (Supabase / Postgres)

```sql
-- 4 tables per spec v0.4
CREATE TABLE tools (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  slug TEXT UNIQUE NOT NULL,
  name TEXT NOT NULL,
  tagline TEXT,
  description TEXT,  -- markdown
  url TEXT NOT NULL,
  logo_url TEXT,
  screenshot_url TEXT,
  primary_category TEXT NOT NULL,  -- FK to categories.slug
  tags TEXT[] DEFAULT '{}',
  pricing_type TEXT,  -- free | freemium | paid | enterprise
  pricing_detail TEXT,
  is_featured BOOLEAN DEFAULT false,
  is_verified BOOLEAN DEFAULT false,
  status TEXT DEFAULT 'pending',  -- pending | approved | rejected
  submitter_email TEXT,
  submitted_at TIMESTAMPTZ DEFAULT now(),
  published_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ DEFAULT now(),
  updated_at TIMESTAMPTZ DEFAULT now()
);
CREATE INDEX tools_status_idx ON tools(status);
CREATE INDEX tools_primary_category_idx ON tools(primary_category);
CREATE INDEX tools_published_at_idx ON tools(published_at DESC);

CREATE TABLE categories (
  slug TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  description TEXT,
  display_order INT DEFAULT 0
);

CREATE TABLE directories (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  slug TEXT UNIQUE NOT NULL,
  name TEXT NOT NULL,
  url TEXT NOT NULL,
  dr INT,
  submission_type TEXT,  -- free | paid | both
  paid_price TEXT,
  link_type TEXT,  -- dofollow | nofollow
  listing_speed TEXT,
  niche_focus TEXT,
  submit_url TEXT,
  notes TEXT,
  status TEXT DEFAULT 'active',  -- active | dead | unknown
  last_checked TIMESTAMPTZ,
  last_verified TIMESTAMPTZ,
  created_at TIMESTAMPTZ DEFAULT now()
);

CREATE TABLE submissions (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  tool_name TEXT NOT NULL,
  tool_url TEXT NOT NULL,
  description TEXT,
  category TEXT,
  pricing_type TEXT,
  submitter_email TEXT NOT NULL,
  logo_url TEXT,
  screenshot_url TEXT,
  status TEXT DEFAULT 'pending',  -- pending | approved | rejected
  rejection_reason TEXT,
  reviewed_at TIMESTAMPTZ,
  created_at TIMESTAMPTZ DEFAULT now()
);

-- RLS
ALTER TABLE tools ENABLE ROW LEVEL SECURITY;
ALTER TABLE submissions ENABLE ROW LEVEL SECURITY;
ALTER TABLE directories ENABLE ROW LEVEL SECURITY;

CREATE POLICY "tools_public_read" ON tools FOR SELECT USING (status = 'approved');
CREATE POLICY "submissions_public_insert" ON submissions FOR INSERT WITH CHECK (true);
CREATE POLICY "directories_public_read" ON directories FOR SELECT USING (status = 'active');
-- Admin policies added in 000002_rls.sql using auth.uid() check
```

## SEO Foundation

- **SSG everywhere**: All public pages use `export const dynamic = 'force-static'` + `generateStaticParams`
- **SoftwareApplication schema** on `/tools/[slug]`
- **ItemList schema** on `/categories/[slug]`, `/directories`, `/latest`
- **next-sitemap** for XML sitemap (config in `next-sitemap.config.js`)
- **robots.txt** allow public, disallow /admin
- **OG/Twitter Card** per page via `app/opengraph-image.tsx` and metadata API
- **Plausible** via `<Script>` in root layout
- **Revalidation**: `revalidateTag()` on admin approve/reject

## Test Strategy

- **Unit (Vitest)**: `lib/` utilities, schema validators
- **Integration (Vitest + Supabase local)**: data model, RLS policies
- **E2E (Playwright)**:
  - Public: home → tool detail → submit form
  - Admin: login → review queue → approve → verify public page shows new tool
  - SEO: verify meta tags, schema markup, sitemap
- **Lighthouse**: target ≥95 SEO, ≥90 performance

## Failure Modes

| Path | Failure | Mitigation |
|---|---|---|
| Tool page SSG | New tool not showing after admin approve | Use `revalidateTag('tools')` on approve; verify with e2e |
| Admin auth | Anyone can hit /admin | Middleware checks Supabase session + allowlist |
| Submission RLS | Public can approve their own | RLS: UPDATE on submissions requires auth.uid() in admin role |
| Sitemap | Stale entries | Dynamic sitemap from DB at build + on-demand revalidate |
| Logo upload | Files pile up in /public | Use Supabase Storage bucket, not local /public |
